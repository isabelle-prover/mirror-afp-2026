\begin{abstract}
  \begin{quote}
	This development studies type consistency and its preservation for the
	Isabelle/HOL semantics of Solidity. It defines consistency properties for
	values, memory, storage, environments, and states, and establishes supporting
	results for initialisation and copying. Within the stated locale assumptions,
	the statement preservation theorem shows that successful execution from a
	type-consistent, fully initialised environment satisfies the state invariant.
	Concrete examples illustrate the assumptions and the use of the theorem.
	The underlying Solidity semantics is imported as a separate session.
	\bigskip
	\noindent\textbf{Keywords:} {Type safety, Smart contracts, Solidity, Program verification, Isabelle/Solidity} 
  \end{quote}
\end{abstract}
