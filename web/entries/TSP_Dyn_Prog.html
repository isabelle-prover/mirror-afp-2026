Travelling Salesman via dynamic programming

Maksym Bortin 📧

September 24, 2026

Abstract

Travelling Salesman Problem (TSP) is well-known to be NP-hard. The computational solution, derived in this theory, follows the Bellman-Held-Karp approach utilising the power set of locations to be visited by the salesman.
